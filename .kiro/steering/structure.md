# Project Structure

```
TextViewer/
├── TextViewer.slnx             # XML solution file (Rider/VS — references .csproj + ClientApp folder)
├── Program.cs                  # .NET entry point — configures PhotinoBlazorAppBuilder, window props
├── App.razor                   # Blazor root component (mounted into #app in index.html)
├── TextViewer.csproj           # MSBuild project file (.NET 10, Photino.Blazor, ng build target)
├── wwwroot/                    # Build output (generated by ng build — do not edit except index.html)
│   ├── index.html              # Host HTML page (source of truth, hand-authored)
│   ├── main.js                 # Angular CLI bundle output
│   ├── polyfills.js            # Angular polyfills bundle
│   └── styles.css              # Compiled styles
├── ClientApp/                  # Frontend source
│   ├── package.json            # npm deps (exact pinned versions)
│   ├── .npmrc                  # save-exact=true, no analytics
│   ├── angular.json            # Angular CLI build config
│   ├── tsconfig.json           # TypeScript config
│   ├── src/
│   │   ├── main.ts             # Angular bootstrap entry point
│   │   ├── styles.css          # Global styles
│   │   └── app/
│   │       ├── app.component.ts
│   │       └── app.component.html
│   └── node_modules/           # npm install output (gitignored)
└── .kiro/
    ├── specs/
    └── steering/
```

## Conventions

- **Single-project structure**: .NET host + frontend source in one repo
- **wwwroot/ is generated**: Angular CLI output lands here. Only `index.html` is hand-authored.
- **MSBuild orchestrates frontend build**: `.csproj` `BuildAngular` target runs `npx ng build` before compile
- **Program.cs uses class with Main**: `[STAThread] public static void Main(string[] args)` (required by Photino)
- **Angular CLI builds to IIFE-equivalent**: Output is standard ES module chunks, loaded via script tags
- **Embedded resources**: All `wwwroot/**` embedded in assembly for single-file deployment
- **No vendored binaries**: All tooling via npm
