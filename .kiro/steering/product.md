# Product

Text Viewer is a cross-platform desktop application for viewing text content. Built with C# .NET 10, it uses Photino.Blazor to host an Angular frontend inside a native OS window.

The application targets Windows, macOS, and Linux using each platform's native webview (WebView2, WebKit).

## Current State

The project is in initial setup — the first milestone is a "Hello World" stub that proves out the Photino.Blazor + Angular integration. No source code has been implemented yet; only the spec exists.
